Désigno

Rien ne m'échappe. Calme et maîtrise : l'urgent se voit d'un coup d'œil, sans faire peur. La couleur n'a que trois sens, et le vert veut dire « sous contrôle ».

Principe 1

La couleur n'a que 3 sens

Vert : sous contrôle. Ambre : à regarder. Rouge : urgent. Tout le reste est en encre et en gris.

Principe 2

Le vert est un état, jamais une action

« J'ai désigné sur l'ANTAI » est un bouton encre. Le vert n'apparaît qu'une fois que c'est fait.

Principe 3

Tout est pilule, sauf la plaque

Boutons, tags, nav, échéance : rayon 9999. La plaque garde son rectangle, pour se repérer d'un coup d'œil.

// lib/echeance.ts — la règle des 45 jours
const DELAI_DESIGNATION_JOURS = 45;

export function calculerEcheance(dateEnvoi: Date): Date {
  const echeance = new Date(dateEnvoi);
  echeance.setDate(echeance.getDate() + DELAI_DESIGNATION_JOURS);
  return echeance;
}

export function niveauEcheance(joursRestants: number) {
  if (joursRestants < 0) return "depassee";
  if (joursRestants <= 2) return "urgent";
  if (joursRestants <= 15) return "a-regarder";
  return "calme";
}
